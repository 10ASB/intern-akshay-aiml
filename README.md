# AI & ML Internship — Akshay

This repository tracks the complete **4-week AI & ML internship**. Work will be organized by week and day, with code, notes, and relevant datasets grouped by topic.

## Internship structure
- `Week-01/` — onboarding, ML landscape, Python data stack, NumPy, Pandas, and dataset exploration
- `Week-02/` — internship exercises and topics covered during the second week
- `Week-03/` — internship exercises and topics covered during the third week
- `Week-04/` — internship exercises, analysis, and final deliverables
- `Datasets/` — relevant practice datasets (only where sharing is permitted)
- `Projects/` — mini-projects, analysis, and final project work

## Week 01 — Day 01 topics
- AI, ML, Deep Learning, and Generative AI overview
- Types of machine learning
- Machine learning lifecycle and production considerations
- NumPy arrays, slicing, broadcasting, and basic operations
- Pandas DataFrames, summaries, grouping, and merging
- Iris and Titanic dataset exploration

The folders will be populated with the actual work and files for each week as they are added. Folder names describe the planned organization; they do not imply that all weeks have already been uploaded.
